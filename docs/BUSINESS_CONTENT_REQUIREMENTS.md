| Page | Needed |
|---|---|
| About | founding story, location, legal name, mission, optional photos |
| Why Laptops HUB | inspection/testing process actually performed; links to approved policies |
| Contact | phone, WhatsApp, email, hours, address; form destination (Shopify contact form, inbox or CRM) |
| FAQ | ordering steps, payment methods, delivery coverage/time, warranty, returns, grading |
| Shipping | regions, couriers, timelines, charges, COD, tracking, damage process |
| Returns | window, eligibility, condition, return shipping, refund method/time, exchange, legal review |
| Warranty | length, coverage, exclusions, claim process, remedy, manufacturer warranty |
| Condition guide | grade names, definitions, inspection steps, per-product grades |
| Order inquiries | response time, reply channel, inbox |
| Privacy | controller, data collected, third parties, retention, rights, cookies, legal review |
| Terms | legal entity, pricing, order acceptance, payment, liability, governing law, legal review |
| Guides (4 + how-to-choose) | editorial sign-off of draft technical copy |

| Usage collections | rule per category (e.g. Workstation = discrete pro GPU), or a usage tag per product |
| New arrivals / Best sellers | created_at dates / sales data |
