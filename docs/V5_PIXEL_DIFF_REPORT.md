## Justified residual differences

- Footer bottom line: V5 text "Catalog snapshot from Shopify export · N products" is false on the live store; replaced with "N products in the catalog" (one line instead of two below 760px → page 28–44px shorter).
- Checkout note: V5 "Prototype cart. Checkout connects to Shopify…" replaced with the truthful "Online checkout is not open yet…" (COD disabled).
- Drawer note: V5 "Prototype cart · checkout not connected" replaced with "Online checkout is not open yet".
- Compare tray is hidden on /compare in both; table identical. Residual is anti-aliasing.
- Sub-0.2% diffs elsewhere are glyph anti-aliasing on text edges (confirmed by inspecting the diff images); no geometry differs.
