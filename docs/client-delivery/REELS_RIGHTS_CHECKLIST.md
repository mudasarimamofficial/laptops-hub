# Generation reels — rights checklist

**Engineering status:** Player, admin CRUD, publish gates, ronin.pk block, and homepage hide-when-empty are complete.

**Content status:** No authorized Laptops HUB video files are in this repository or published in production.

## Before publishing any reel

1. Confirm the file is owned by Laptops HUB (filmed by staff) **or** licensed in writing.  
2. Host on an HTTPS origin Laptops HUB controls (Blob / CDN / Supabase Storage). Direct `.mp4` / `.webm` / `.mov` only.  
3. Do **not** use ronin.pk or any other shop’s media — refused at form, API and database.  
4. Set rights to Owned or Licensed; for Licensed, fill the rights note (who, date, terms).  
5. Optional: creator name only with written consent.  
6. Publish → homepage “Generation Laptops HUB” row appears.
